attn-res

Attention Residuals（深度维度注意力残差）：用 softmax attention 替代固定等权残差累加，实现 input-dependent 的深度信息选择性聚合。涵盖 Full AttnRes、Block AttnRes、time-depth duality、structured-matrix 统一视角。含 fla 库的 Triton 融合 kernel 实现解析。

finetuning-efficiency

预训练模型的下游学习效率：给定预训练模型，能否预测学会下游任务所需的时间／数据量。Q1 = 模型大小，Q2 = 预训练程度。核心张力：prompting 口径下 loss 像充分统计量（Du），SFT 口径下出现 catastrophic overtraining（Springer）。覆盖迁移 scaling law、可塑性衰减、loss-to-loss、学习曲线外推（Hestness / Rosenfeld / Mohr / LCDB 1.1 / MPL）、持续预训练（D-CPT / CMR / rewarm / PTPP-aware）与 Pythia/OLMo/LLM360 实验床。

深度扩展与层复制（depth expansion / layer stacking）：函数保持增长、渐进堆叠、增长调度、层位置选择与 inductive bias。涵盖 Net2Net、StackBERT、GStack、MIDAS 等 16 篇论文，核心发现：复制中间层能引入有利于推理的 inductive bias。
